DESIGN SYSTEM
=====================================

CORES:
- Primary: #000000 (preto)
- Secondary: #FFFFFF (branco)
- Accent: #D4AF37 (ouro - CTAs e destaque)
- Dark BG: #1A1A1A
- Text Muted: #999999

TIPOGRAFIA:
- Font: Inter (Google Fonts)
- Heading 1 (H1): Bold, 56-72px, line-height 1.2
- Heading 2 (H2): Semibold, 32-42px
- Heading 3 (H3): Semibold, 18-24px
- Body: Regular, 16-18px, line-height 1.8
- Caption: Italic, 14px

ESPAÇAMENTO:
- Padding seções: 80-120px (vertical)
- Padding container: 40px (horizontal, desktop), 20px (mobile)
- Gap entre elementos: 40-60px
- Muito espaço branco (respiração)

LAYOUT:
- Container max-width: 1400px
- Imagens: full-width ou 50% + texto
- Hero: 100vh
- Cards: hover com scale(1.05) + shadow suave
- Transições: 0.3s cubic-bezier(0.4, 0, 0.2, 1)

RESPONSIVIDADE:
- Mobile: < 768px (1 coluna, full-width)
- Tablet: 768-1024px (2 colunas)
- Desktop: > 1024px (3-4 colunas, layouts complexos)
